# OpenSooq Growth Audit

**Live → https://eddieatadapty.github.io/opensooq-flow-rebuild/**

Five ideas to turn more OpenSooq users into subscribers, each built into a clickable version of OpenSooq's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | The listing goes live before any price | +10–20% CR to purchase |
| 02 | Promote it on their own listing | +10–20% CR to purchase |
| 03 | Arrive on the ad’s promise, and say what’s free | +5–15% CR to purchase |
| 04 | One question the ad didn’t answer, used twice | +5–15% CR to purchase |
| 05 | Catch the people who close it | +10–15% ARPU |

Every price, rating and feature comes from OpenSooq's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for OpenSooq, whose money comes from listing promotion rather than subscriptions. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
